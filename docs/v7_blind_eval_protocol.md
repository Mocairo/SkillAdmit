# V7 Blind Evaluation Protocol

Last updated: 2026-05-21

## 1. Purpose

V7 is the blind evaluation set created after using v6 as development data.

V6 has now been used to improve the controller, so v6 is a development/regression
set. V7 is the current clean one-shot evaluation result.

## 2. Controller Versions

Development controller:

```text
skilladmit/controllers/rule_based_controller_v6_dev.py
```

Default current controller:

```text
skilladmit/controllers/rule_based_controller.py
```

The default controller currently mirrors `rule_based_controller_v6_dev.py`.

Frozen v7-evaluation controller:

```text
skilladmit/controllers/rule_based_controller_v6_frozen.py
```

Do not edit `rule_based_controller_v6_frozen.py` using v7 errors and still call
v7 held-out.

## 5. Evaluation Commands

Generate v7:

```bash
python scripts/build_v7_blind_admission_samples.py
```

Evaluate frozen controller:

```bash
python scripts/evaluate_controller_module.py \
  --controller-module skilladmit.controllers.rule_based_controller_v6_frozen \
  --samples benchmark/admission_samples/v7_blind_admission_samples.jsonl \
  --output benchmark/admission_samples/v7_frozen_controller_predictions.jsonl
```

Inspect frozen errors:

```bash
python scripts/inspect_frozen_controller_errors.py \
  --samples benchmark/admission_samples/v7_blind_admission_samples.jsonl \
  --predictions benchmark/admission_samples/v7_frozen_controller_predictions.jsonl
```

## 7. Caveat

V7 was generated after looking at v6 errors but before tuning on v7. Therefore
it is the current clean controller-evaluation result.

However, for a paper-grade benchmark, a stronger protocol should eventually use
independently authored or randomized samples so the same developer is not both
the controller author and the blind-set author.

## 8. What Not To Do

Do not tune `rule_based_controller_v6_frozen.py` on v7 and report v7 as
held-out.

If v7 errors are used to improve the method, v7 becomes a development set. The
next clean evaluation must be v8.

## 9. Recommended Next Step

There are two reasonable next paths:

```text
Path A: stop controller tuning and add baselines/downstream validation.
Path B: use v7 as development data, create v7_dev, freeze it, and build v8 blind.
```

For the paper, Path A is now more valuable. The controller has enough benchmark
machinery to support baseline comparison and downstream artifact validation.
