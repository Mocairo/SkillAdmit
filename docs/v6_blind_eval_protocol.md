# V6 Blind Evaluation Protocol

Last updated: 2026-05-21

## 1. Purpose

V6 is the blind evaluation set created after using v5 as development data.

V5 was used to improve the controller, so v5 is now a development/regression
set. V6 is the current clean one-shot evaluation result.

## 2. Controller Versions

Development controller:

```text
skilladmit/controllers/rule_based_controller_v5_dev.py
```

Default current controller:

```text
skilladmit/controllers/rule_based_controller.py
```

The default controller currently mirrors `rule_based_controller_v5_dev.py`.

Frozen v6-evaluation controller:

```text
skilladmit/controllers/rule_based_controller_v5_frozen.py
```

Do not edit `rule_based_controller_v5_frozen.py` using v6 errors and still call
v6 held-out.

## 5. Evaluation Commands

Generate v6:

```bash
python scripts/build_v6_blind_admission_samples.py
```

Evaluate frozen controller:

```bash
python scripts/evaluate_controller_module.py \
  --controller-module skilladmit.controllers.rule_based_controller_v5_frozen \
  --samples benchmark/admission_samples/v6_blind_admission_samples.jsonl \
  --output benchmark/admission_samples/v6_frozen_controller_predictions.jsonl
```

Inspect frozen errors:

```bash
python scripts/inspect_frozen_controller_errors.py \
  --samples benchmark/admission_samples/v6_blind_admission_samples.jsonl \
  --predictions benchmark/admission_samples/v6_frozen_controller_predictions.jsonl
```

## 7. Interpretation

The controller is now strong on:

```text
discard: 10/10
distill_into_skill: 10/10
```

It is still weak on:

```text
promote_to_rule: 3/10
store_as_memory: 6/10
defer: 4/10
```

Main observed failure pattern:

```text
The marker-based controller recognizes harmful operational patterns and
procedural skills, but still struggles with abstract global rules and local
metadata when wording changes.
```

This supports the argument that a stronger SkillAdmit method should not rely
only on phrase matching. It needs structured artifact-level reasoning.

## 8. What Not To Do

Do not tune `rule_based_controller_v5_frozen.py` on v6 and report v6 as
held-out.

If v6 errors are used to improve the method, v6 becomes a development set. The
next clean evaluation must be v7.

## 9. Recommended Next Step

Create:

```text
skilladmit/controllers/rule_based_controller_v6_dev.py
```

Use v6 as development data to improve:

```text
abstract rule recognition
local metadata/memory recognition
conflict-driven defer recognition
separation of global constraints from procedural skills
```

Then freeze the improved controller and build v7 blind samples.

The current result suggests the next method should move beyond flat marker
lists. A better design would first classify the candidate artifact level:

```text
local fact
reusable procedure
global constraint
harmful workaround
insufficient/conflicting evidence
```

and only then apply the five admission labels.
